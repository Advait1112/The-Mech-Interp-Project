# The-Mech-Interp-Project
The Mechanistic Interpretability Project aims to uncover some ground truths about the field, and make me understand it better, for me to further make the field better.

## Contents

### 📚 Literature Survey
[`research-papers/mech-interp-survey/`](research-papers/mech-interp-survey/)

A comprehensive, annotated table of **20 foundational and recent papers** (2021–2026) covering:
- Sparse Autoencoders (SAEs) & Dictionary Learning
- Feature Superposition & Monosemanticity
- Feature Geometry, Compositional Arithmetic & Latent Space Dynamics
- Circuits, Automated Discovery & Foundational Frameworks

Sources include Anthropic's Transformer Circuits Thread, Google DeepMind (Gemma Scope), OpenAI, and high-impact arXiv pre-prints.

A companion [`download_papers.sh`](research-papers/mech-interp-survey/download_papers.sh) script downloads all 15 available arXiv PDFs with a single command:

```bash
bash research-papers/mech-interp-survey/download_papers.sh
```
